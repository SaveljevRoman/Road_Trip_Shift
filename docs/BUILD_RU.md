# Сборка Road Trip Shift

[Описание проекта](../README_RU.md) · [На английском](BUILD.md)

## Требования

- Windows x64 и PowerShell 7 (`pwsh`).
- MinGW-w64 `g++` с C++17. Закреплённый вариант — [w64devkit 2.11.0](https://github.com/skeeto/w64devkit/releases/tag/v2.11.0).
- Заголовки SCS SDK 1.16 включены в `third_party/scs_sdk/include/`.
- Для полной проверки нужен локальный EXE поддерживаемой ATS. Игра и файлы DLC не распространяются.

Команды выполняются из корня репозитория. Замените `path_to_compiler`, `path_to_file` и `path_to_game` своими путями.

## Компиляция и проверки

```powershell
pwsh -File ./plugin/build.ps1 -Compiler 'path_to_compiler/g++.exe' -GameExe 'path_to_game/bin/win_x64/amtrucks.exe'
```

Можно скачать переносимый компилятор: скрипт сверит SHA-256 архива и распакует его в игнорируемую Git папку `research/toolchain/`. Укажите 7-Zip или добавьте `7z` в PATH:

```powershell
pwsh -File ./scripts/bootstrap-toolchain.ps1 -SevenZip 'path_to_file/7z.exe'
pwsh -File ./plugin/build.ps1 -GameExe 'path_to_game/bin/win_x64/amtrucks.exe'
```

Сборка находит переносимый компилятор или `g++` из PATH. Путь к игре автоматически не выбирается: для полной проверки передайте `-GameExe`. Сборка без установленной игры:

```powershell
pwsh -File ./plugin/build.ps1 -NoGame
```

Без EXE проверки логики и нативного стенда выполняются, но 20 участков игрового кода не сверяются. Ограничение отражается в манифесте. Для публикации обязателен `-GameExe`.

## Результаты и публикация

| Путь | Содержимое |
| --- | --- |
| `.build/tests/` | Проверочные EXE, локальные логи и тестовые файлы |
| `.build/package/` | Дерево установки, установщик, инструкции EN/RU, лицензии и манифест |
| `.build/road_trip_shift_0.3.1_win64.zip` | Установочный архив; при `-SkipPackage` не создаётся |
| `release/` | Обновляется только с `-Publish`: DLL, ZIP, манифест и контрольные суммы |

Обновление готовой сборки в репозитории:

```powershell
pwsh -File ./plugin/build.ps1 -GameExe 'path_to_game/bin/win_x64/amtrucks.exe' -Publish
pwsh -File ./scripts/Check-PublicFiles.ps1
git diff --stat
```

`-Publish` требует проверки игрового EXE и несовместим с `-SkipPackage`. Библиотеки среды выполнения компилятора подключаются статически, символы удаляются, пути заменяются относительным префиксом, время в PE фиксируется. Манифест содержит хеши и результаты проверок без имён пользователя и путей компьютера. Сборка не устанавливает плагин и не запускает/закрывает ATS.

## Что проверяется

Проверяются нажатия и возврат режима, защита круиза, распознавание машин SDK, источники изменения режима, отказ на неизвестном процессе, выполнение нативных вставок, восстановление байтов и отключение диагностики в изолированной памяти. На тестовых файлах проверяются ограничение размера и смена логов. С `-GameExe` сверяются точный хеш и 20 участков кода игры. Эти проверки не заменяют поездку.

```powershell
pwsh -File ./scripts/Check-Instructions.ps1
pwsh -File ./scripts/Check-PublicFiles.ps1 -History
```

Локальный повтор для детектора: `.build/tests/logic-tests.exe path_to_file/telemetry.csv`. Он проверяет распознавание событий без моделирования движения на другой передаче. Телеметрия и результаты в Git не добавляются. Перед изменением перехватов прочитайте [техническое описание](DEVELOPMENT.md). После обновления игры заново исследуйте каждый участок вместо простой замены хеша.
