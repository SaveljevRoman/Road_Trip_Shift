# Установка Road Trip Shift

Версия **0.3.1 — экспериментальная**. Эта инструкция также вложена в ZIP. В репозитории: [Описание проекта](../README_RU.md) · [На английском](INSTALL.md).

## Требования

Windows x64 и Road Trip: Ford. Проверено на ATS **1.62.1.1**. Адреса кода находятся автоматически по сигнатурам инструкций; ограничений по версии или хешу EXE нет. Другие сборки игры пока не проверены. Мультиплеер не проверен. Базовое поведение проверялось с 0.2.2; новая защита круиза в 0.3.1 ещё требует проверки в поездке. Новый клавиатурный ввод газа и поиск адресов также ещё требуют проверки в поездке.

## Ручная установка

1. Закройте ATS обычным способом. Скачайте и распакуйте установочный ZIP; сам архив в `mod` не копируется.
2. В Steam выберите ATS → Управление → Просмотреть локальные файлы. Откроется `path_to_game`.
3. Скопируйте папку `bin` из архива в каталог игры с объединением папок. При необходимости создайте `plugins`. Должно получиться:

```text
path_to_game/
  bin/win_x64/
    amtrucks.exe
    plugins/
      road_trip_shift.dll
      road_trip_shift/
        road_trip_shift.ini
```

Для работы достаточно DLL: без INI используются встроенные значения. При обновлении сохраните существующий INI. При распространении сохраняйте папку `licenses` из ZIP. Библиотеки среды выполнения компилятора встроены статически; дополнительные DLL компилятора не требуются.

4. Запустите ATS и подтвердите использование SDK. Выберите поддерживаемый Ford, автоматическую коробку и нужный режим адаптивных переключений. Для клавиатурного разгона двойным нажатием газа используется штатная функция полного газа при двойном нажатии. Плагин автоматически следует назначению газа в ATS; отдельная настройка клавиши не нужна.

Активация через менеджер модов для DLL не нужна. `amtrucks.exe` заменять не требуется.

## Необязательный установщик PowerShell

Из каталога распакованного ZIP, в PowerShell 7:

```powershell
pwsh -File ./Install.ps1 -GameRoot 'path_to_game'
```

Установщик откажется работать при запущенной игре, сверит хеш DLL, сохранит предыдущую DLL и существующий INI. Файл `installation.json` с информацией об установке и резервные копии находятся в `plugins/road_trip_shift/`. Профили и другие плагины он не меняет.

## Настройки

При закрытой ATS отредактируйте `bin/win_x64/plugins/road_trip_shift/road_trip_shift.ini`, затем перезапустите игру:

| Секция / ключ | По умолчанию | Назначение |
| --- | --- | --- |
| `plugin / enabled` | `1` | `0` отключает поведение плагина |
| `input / double_tap_ms` | `300` | Интервал между нажатиями, мс; ограничен 100–700 |
| `input / controls_file` | пусто | Необязательный путь к controls.sii; пустое значение включает поиск активного профиля |
| `cruise / anti_hunt` | `1` | `0` отключает новую защиту круиза для сравнения |
| `logging / enabled` | `1` | `0` отключает запись диагностических файлов, обновление состояния и сообщения плагина в игровом логе |
| `logging / max_total_mb` | `50` | Общий лимит логов событий и таблиц телеметрии в МиБ; ограничен 1–1024 |
| `logging / sample_ms` | `200` | Интервал телеметрии, мс; ограничен 100–2000 |

Двойное нажатие назначенной клавиши газа временно включает мощностной режим КПП, пока удерживается второе нажатие. Отпускание клавиши возвращает выбранный режим, даже если на геймпаде газ ещё удерживается. Одиночное клавиатурное нажатие и круиз сохраняют выбранный режим. Кнопки геймпада, курки и педали сами по себе не включают кикдаун плагина. После запуска, паузы, потери фокуса, перезапуска таймера или смены машины отпустите клавишу перед новым двойным нажатием. Запасной привязки к W нет.

Плагин читает `mix dforward` из `controls.sii` активного профиля и подтверждает клавиатурное нажатие свежим сигналом газа из SDK. Поддерживаются буквы, цифры основного ряда, F1–F12, стрелки, пробел, Tab, Backspace, Esc, отдельные Shift/Ctrl/Alt, клавиши навигации и основные знаки пунктуации. Поддерживаются простые альтернативные назначения через OR; варианты от контроллера игнорируются. Сложные выражения, сочетания через AND, неизвестные имена клавиш, Enter и цифровой блок не поддерживаются: их физические варианты нельзя надёжно различить выбранным способом опроса Windows. При таком назначении клавиатурный кикдаун отключается. Если программа управления геймпадом эмулирует клавиатурные события, они считаются клавиатурным вводом.

Профиль определяется по последнему пути профиля в текущем игровом логе, в папке игры внутри «Документов» либо каталоге запуска с `-homedir`. Если автоматический поиск недоступен, задайте `input / controls_file` как `path_to_file/controls.sii`; относительный путь считается от этого каталога игровых данных. Назначения перечитываются примерно раз в секунду и после изменения активности/управления. Игра должна сохранить изменённое назначение, прежде чем плагин его подхватит. Лог и файл управления не изменяются.

Существующий INI можно сохранить. Устаревший ключ `input / analog_kickdown` игнорируется: теперь кикдаун плагина доступен только с назначенной клавиатурной кнопки газа. Интервал по-прежнему задаётся через `input / double_tap_ms`.

## Логи и диагностика

При включённой диагностике рядом с DLL создаются `plugins/road_trip_shift/status.json` и `plugins/road_trip_shift/logs/`. Это телеметрия машины, нажатий и коробки; сетевой отправки нет. Перед отправкой просмотрите файлы: игровой лог и файл `installation.json` с информацией об установке могут содержать пути к папкам на вашем компьютере.

По умолчанию логи событий и таблицы телеметрии вместе ограничены **50 МиБ**, включая файлы предыдущих версий. Длинная сессия делится на части размером до 5 МиБ, каждая таблица начинается с заголовка. При запуске и смене части удаляются самые старые завершённые файлы. Текущая часть сначала закрывается. Посторонние файлы, игровой лог и резервные копии установщика в этот лимит не входят и не удаляются. Если старые файлы удалить не получается, запись на диск прекращается, чтобы объём не рос дальше. `status.json` остаётся небольшим, поскольку перезаписывается. Отключение диагностики сохраняет уже записанные файлы и не отключает функции коробки.

- `hooks_ready` — установка перехватов; `vehicle_supported` — распознавание машины. `reader_calls` и `shadow_reads` подтверждают обращения к чтению режима. Сами по себе эти признаки не доказывают правильное поведение в поездке.
- Поля `keyboard_binding_ready` и `input_sample_valid` в status показывают наличие назначения и свежего сигнала газа. Событие `KEYBOARD_BINDING source=controls_sii` записывает готовность без локальных путей.
- В CSV поле `input_down` заменяет `w_down` и отражает действие газа из SDK; события `THROTTLE DOWN/UP source=game_input` показывают его нажатия и отпускания. Опрашиваются только клавиши из клавиатурного назначения газа.
- `CONFIG_MODE_CHANGED source=game_setting` — изменение настройки игры, в том числе при загрузке профиля. `KICKDOWN ON/OFF source=plugin` — временный запрос плагина. При уже выбранном мощностном режиме КПП возможно `value_changed=0`.
- `CRUISE_GUARD source=cruise_load`, `cruise_guard_cap`, `cruise_guard_clamps` — защита от неудачных повышений. `effective_brake` помогает отличить торможение адаптива от недостатка тяги.
- Если перехваты не применились, проверьте лог: найдены ли сигнатуры инструкций и нет ли конфликта с другими плагинами коробки.
- Сравните одиночное нажатие газа, двойное нажатие с отпусканием и круиз при разных скоростях и нагрузках. Высшая передача сама по себе не критерий успеха: машина должна поддерживать скорость. Адаптивный круиз может снижать скорость из-за трафика.


## Удаление

Закройте ATS и удалите только `bin/win_x64/plugins/road_trip_shift.dll`. Папку `road_trip_shift` можно удалить, если больше не нужны настройки, логи и резервные копии. Не удаляйте общую папку `plugins`. Изменения памяти исчезают при выходе из ATS.
